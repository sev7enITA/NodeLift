# First physical Android timing check

3 November 2026. Xiaomi 17 Ultra, reported as Xiaomi 25128PNA1C, companion 0.2.13 build 16. The host observed native build `timing-v1-0.2.13`, O3, timing schema 1 and bounded-lookahead capability. The compiled artifact flags and hash are independently recorded in the release manifest; device capabilities are authenticated self-reports.

Three 16-token requests used Qwen2.5 1.5B Q4_K_M on the Mac and 0.5B Q4_K_M on the phone: host-only, remote serial, then remote bounded lookahead. Both remote requests matched the host token hash, accepted 9 of 26 submitted draft tokens, and completed generation without fallback. Each emitted 16 final tokens. The remaining 17 submitted proposals were uncommitted. The bounded request reported 17 additionally predicted tokens: 4 reused as proposals, 1 consumed by the authoritative prefix and 12 discarded. Reused proposals are not automatically accepted target output.

The bounded finish request expired after approximately 2 seconds. Its cleanup is explicitly incomplete, and subsequent device contacts stopped. The cause is unresolved. Missing work is unknown, not zero. Raw [serial](remote_draft-serial.json), [bounded](remote_draft-bounded_v1.json), [host](host-serial.json), [plan](manifest.json) and [phase summary](summary.json) are retained.

This is a protocol and instrumentation check, **not a matched performance comparison**. It has one prompt, fixed order and a cold first host request. Draft KV history differs between requests. Do not rank these raw durations or attribute a causal benefit to O3 from this check. Requested phone CPU threads/context remain saved device preferences and are not yet exported in the worker telemetry. Phone backend is ARM64 CPU; the Mac uses Metal. The topology was described by the owner as the Xiaomi hotspot supplying the Mac; Android reported its active transport as other/not detected. There is no wired comparison, energy measurement or sustained thermal qualification.

The compatible 1B draft was subsequently transferred. Two larger 8B/1B attempts were interrupted at sequence 9 and retained in the parent report. The prepared [collector](../benchmark-wireless.py) freezes randomized arms, warmups and matching model identities before measured runs. It retains failures and stops on scope drift. The full repeated physical pilot remains incomplete.
