  function contribution(run) {
    const empty = {measured:false, applicable:true, generated:null, mobile:null, host:null, proposed:null, uncommitted:null, share:null, nodeId:run?.node_id || null};
    if (!run) return empty;
    if (run.backend && run.backend !== 'native') return {...empty, applicable:false};
    if (!Array.isArray(run.blocks) || !run.blocks.length) return empty;
    let generated=0, mobile=0, proposed=0;
    for (const block of run.blocks) {
      if (!block || !count(block.generated) || !count(block.accepted) || !count(block.proposed) || block.accepted > block.generated || block.accepted > block.proposed || !['host','remote_draft','local_draft','lookup'].includes(block.effective_mode)) return empty;
      generated += block.generated;
      if (block.effective_mode === 'remote_draft') {
        if (run.mode !== 'remote_draft' || !run.node_id) return empty;
        mobile += block.accepted; proposed += block.proposed;
      }
    }
    if (!generated || (run.metrics?.generated_tokens !== undefined && run.metrics.generated_tokens !== generated)) return empty;
    return {...empty,measured:true,generated,mobile,host:generated-mobile,proposed,uncommitted:proposed-mobile,share:mobile/generated};

# External design review and disposition

GLM-5.3 was selected in z.ai; Max effort had been selected in the same review session. The model reviewed the supplied protocol description and stated test scope, **not the source or physical devices**. Its response reports no observed defect and separates inference from untested areas. The response is retained in `glm-design-review.txt`; the earlier performance-methodology review remains separate from this pairing deliverable. Gemini 4 High was unavailable under the account quota observed earlier in this session (reset displayed as 1 November 08:45). No substitute Gemini model or successful Gemini QR review is claimed.

- **Optical density:** record RSA-2048 identity generation, QR version 27 / 125 modules / medium error correction for the 1,114-byte isolated fixture. The native canvas is 532px with a four-module quiet zone; its 460px browser rendering was decoded independently by ZXing. Actual distance, focus, glare and first-scan success on hardware are unmeasured.
- **TLS/SAN:** `make_identity` explicitly emits an IP-address SAN for the chosen bind address and loopback. The Swift protocol check actually completed positive TLS enrollment, upload/download and heartbeat as well as rejecting a wrong certificate. These are macOS client tests, not iPhone qualification. AVFoundation decodes the camera image; URLSession/Security handles iOS TLS. Android explicitly checks the leaf certificate digest and keeps hostname validation.
- **Clock:** the server enforces its stored invitation expiry; it never accepts a caller-supplied expiry as authority. Seconds are used in the compact payload. A badly skewed phone clock can reject an otherwise valid invitation early; no clock-skew tolerance is claimed.
- **Consume/Close race:** added 24 concurrent consume/revoke trials. SQLite serialization allows either completed pairing or revoked-unused invitation, never replay. Close does not revoke a session that already paired; the device's Revoke pairing control does. The desktop generation counter governs invitation creation responses, not a mobile enrollment response.
- **Trust/user intent:** desktop and phone both display the host and the same fingerprint prefix. The guide recommends the in-app scanner and documents custom-scheme non-exclusivity. Pairing alone does not send a prompt: host inference requires an authenticated run request; native remote mode also requires the selected node ID and the phone's LLM opt-in/model. This release does not add a separate approval registry, device attestation or protection against deliberate disclosure of a live invitation.
- **Credential lifetime:** the invite is deleted atomically and replaced by a separate random 256-bit bearer token delivered over pinned TLS; Android Keystore / iOS Keychain store the session. The invitation is not reused as the worker token. Cryptographic channel derivation is not required or claimed.
- **Admin/fallback:** status returns only `pending`; both new endpoints require the existing admin bearer token and loopback Host/Origin checks. Manual inputs and scanned inputs use the same new-ticket validator. Manual copying still leaves user-controlled clipboard exposure.
- **IP changes:** certificate SAN, bind address and generated invitation use the startup address. Existing state refuses an IP mismatch; the guide explains use of a new state directory and re-pairing after a network change. Network selection is not automatically repaired by QR scanning.

Physical camera scanning is the outstanding release qualification, and is disclosed in the experimental release notes and download metadata. None of this review establishes inference speed or large-model capacity.

## Automatic mobile checks

The companion fetches the small public [mobile release manifest](https://www.fabriziodegni.com/NodeLift/data/mobile-downloads.json) over HTTPS. The experimental release channel includes published NodeLift companion prereleases. Three numeric version components are compared numerically, followed by the build number for the same version. An older manifest cannot trigger a downgrade prompt. Malformed or oversized responses fail without changing pairing or the engine.

A fresh process checks at launch even if a prior check was recent. A successful check schedules the next check seven days later. Failed due checks retry after one hour while the process runs. There is one request in flight at a time. The OS may suspend timers, especially on iOS or during Android power saving; the app performs an overdue check when it returns to the foreground. It cannot promise background execution while the OS has suspended or terminated it.

**Check now** is an explicit retry. The UI distinguishes checking, a newer release, no newer release and an unavailable check. Installation is always chosen by the user through the official download route. No APK, IPA or executable is downloaded or installed by the checker. iOS signing requirements still apply.

Checks send a generic app user-agent and no device identifier, pairing token, prompt, model data or diagnostic report. The public server necessarily receives the network request and source IP like any HTTPS website. This is metadata discovery over HTTPS, not a signed automatic installer. A future installer would need separate package authenticity, platform signing and rollback design.

## Diagnostics

**Export diagnostics** and **Clear diagnostics** are separate from updates. Export uses the platform share sheet; no log upload runs automatically. See [wireless support and crash-report limitations](MOBILE_DIAGNOSTICS.md).

Opening a browser or share destination may pause iOS delegated work under its existing foreground lifecycle. Return to NodeLift and resume when ready. Opening About or checking metadata does not alter engine consent or pairing.

## Verification

See [0.2.6 release evidence](evidence/companion-0.2.6/README.md) for automated checks, builds, external-review scope and device limitations. Earlier [About evaluation](evidence/about-2026-11-01/model-review.json) covers the earlier manual-link UI only; it is not evidence of these new automatic checks.

/** Bounded public manifest and changelog requests; never attaches node credentials or device identifiers. */
object UpdateMonitor {
    private const val ENDPOINT="https://www.fabriziodegni.com/NodeLift/data/mobile-downloads.json"
    private val handler=Handler(Looper.getMainLooper())
    private val executor=Executors.newSingleThreadExecutor()
    @Volatile var checking=false;private set
    @Volatile var available=false;private set
    @Volatile var details:ReleaseDetails?=null;private set
    @Volatile var message:UiText=ui("Updates have not been checked yet.");private set
    private var started=false
    private var context:Context?=null
    private val timer=Runnable {context?.let { onResume(it) }}
    @Synchronized fun start(context:Context) {
        if(started)return
        started=true;this.context=context.applicationContext
        check(context) // Every new application process, even if last success was recent.
    }
    fun onResume(context:Context) {
        val prefs=context.getSharedPreferences("updates",0)
        if(UpdatePolicy.due(System.currentTimeMillis(),prefs.getLong("success",0),prefs.getLong("attempt",0)))check(context)
        else schedule(context)
    }
    private fun schedule(context:Context) {
        val prefs=context.getSharedPreferences("updates",0)
        val now=System.currentTimeMillis()
        val success=prefs.getLong("success",0);val attempt=prefs.getLong("attempt",0)
        val next=if(success>0 && now>=success && now-success<UpdatePolicy.WEEK_MS)success+UpdatePolicy.WEEK_MS else attempt+UpdatePolicy.RETRY_MS
        handler.removeCallbacks(timer)
        handler.postDelayed(timer,(next-now).coerceIn(1000,UpdatePolicy.WEEK_MS))
    }
    @Synchronized fun check(context:Context,manual:Boolean=false) {
        if(checking)return
        val app=context.applicationContext
        val prefs=app.getSharedPreferences("updates",0)
        // A manual action may retry immediately, but cannot fan out parallel requests.
        checking=true;available=false;details=null;message=ui("Checking for updates…")
        prefs.edit().putLong("attempt",System.currentTimeMillis()).apply()
        Diagnostics.record(DiagnosticEvent.UPDATE_CHECK)
        executor.execute {
            try {
                val manifest=fetch(ENDPOINT)
                val changelog=fetch("https://www.fabriziodegni.com/NodeLift/data/changelog.json")
                val info=app.packageManager.getPackageInfo(app.packageName,0)
                val current=CompanionRelease(info.versionName ?: error("Version unavailable"),if(Build.VERSION.SDK_INT>=28)info.longVersionCode else @Suppress("DEPRECATION") info.versionCode.toLong())
                val verified=ReleaseMetadata.parse(manifest,changelog,current)
                val release=verified.release
                details=verified
                available=release>current
                message=if(available)ui("Update available: {0} · build {1}",release.version,release.build) else ui("No newer companion release was found.")
                prefs.edit().putLong("success",System.currentTimeMillis()).apply()
                Diagnostics.record(if(available)DiagnosticEvent.UPDATE_AVAILABLE else DiagnosticEvent.UPDATE_CURRENT)
            } catch(error:Exception) {
                available=false;details=null
                message=ui("Update check unavailable. Check your connection or try again later.")
                Diagnostics.record(DiagnosticEvent.UPDATE_FAILED,error)
            } finally {checking=false;schedule(app)}
        }
    }
    private fun fetch(endpoint:String):Map<*,*> {
        val connection=URL(endpoint).openConnection() as HttpsURLConnection
        try {
            connection.apply {connectTimeout=10000;readTimeout=10000;instanceFollowRedirects=false;useCaches=false;setRequestProperty("Accept","application/json");setRequestProperty("User-Agent","NodeLift-update-check")}
            require(connection.responseCode==200)
            require(connection.contentType?.substringBefore(';')?.trim()?.lowercase()=="application/json")
            val data=connection.inputStream.use{it.readBytesBounded(524288)}
            // Bound nesting before the platform JSON parser to avoid stack exhaustion.
            var depth=0;var quoted=false;var escaped=false
            for(byte in data){val c=byte.toInt().toChar();if(quoted){if(escaped)escaped=false else if(c=='\\')escaped=true else if(c=='"')quoted=false}
                else if(c=='"')quoted=true else if(c=='{' || c=='['){depth++;require(depth<=16)} else if(c=='}' || c==']'){depth--;require(depth>=0)}}
            require(!quoted && depth==0)
            fun value(raw:Any?):Any?=when(raw){
                is JSONObject -> raw.keys().asSequence().associateWith{value(raw.get(it))}
                is org.json.JSONArray -> (0 until raw.length()).map{value(raw.get(it))}
                JSONObject.NULL -> null
                else -> raw
            }
            return value(JSONObject(String(data,Charsets.UTF_8))) as Map<*,*>
        } finally {connection.disconnect()}
    }
    private fun java.io.InputStream.readBytesBounded(limit:Int):ByteArray {
        val out=java.io.ByteArrayOutputStream();val buffer=ByteArray(4096)
        while(true) {val n=read(buffer);if(n<0)break;require(out.size()+n<=limit);out.write(buffer,0,n)}
        return out.toByteArray()
    }
}

package dev.nodelift.companion

/** Public companion channel uses three numeric version components plus a monotonic build. */
data class CompanionRelease(val version:String,val build:Long) : Comparable<CompanionRelease> {
    private val parts=version.split('.').map { it.toLongOrNull() ?: -1 }
    init { require(version.matches(Regex("[0-9]{1,6}\\.[0-9]{1,6}\\.[0-9]{1,6}")) && build in 1..Int.MAX_VALUE) }
    override fun compareTo(other:CompanionRelease):Int {
        for(i in parts.indices) {val result=parts[i].compareTo(other.parts[i]);if(result!=0)return result}
        return build.compareTo(other.build)
    }
}
object UpdatePolicy {
    const val WEEK_MS=7*24*60*60*1000L
    const val RETRY_MS=60*60*1000L
    fun due(now:Long,lastSuccess:Long,lastAttempt:Long):Boolean {
        if(now<lastSuccess || now<lastAttempt)return true // Clock correction must not postpone indefinitely.
        return (lastSuccess<=0 || now-lastSuccess>=WEEK_MS) && (lastAttempt<=0 || now-lastAttempt>=RETRY_MS)
    }
}

/** Validated public metadata, never an instruction to install or a verified artifact payload. */
data class ReleaseDetails(val release:CompanionRelease,val date:String,val title:String,val changes:List<String>,val validation:String,val limitations:String,val artifact:String,val bytes:Long,val sha256:String,val url:String)
object ReleaseMetadata {
    private fun obj(value:Any?):Map<*,*> = value as? Map<*,*> ?: error("Expected object")
    private fun string(value:Any?,limit:Int):String {
        val s=value as? String ?: error("Expected string")
        require(s.isNotBlank() && s.length<=limit && s.none { it<' ' && it!='\n' && it!='\t' });return s
    }
    private fun integer(value:Any?,maximum:Long):Long {
        require(value is Int || value is Long);val n=(value as Number).toLong();require(n in 1..maximum);return n
    }
    fun parse(manifest:Map<*,*>,changelog:Map<*,*>,current:CompanionRelease):ReleaseDetails {
        val release=CompanionRelease(string(manifest["version"],32),integer(manifest["build"],Int.MAX_VALUE.toLong()))
        require(release>=current && release.build>=current.build)
        require(integer(changelog["schema_version"],1)==1L)
        val date=string(manifest["published_at"],32)
        require(date.matches(Regex("[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}Z")))
        java.time.Instant.parse(date)
        val entries=changelog["releases"] as? List<*> ?: error("Expected releases")
        require(entries.size in 1..256)
        require(obj(entries.first())["version"]==release.version && integer(obj(entries.first())["build"],Int.MAX_VALUE.toLong())==release.build)
        val matches=entries.map { obj(it) }.filter { it["version"]==release.version && it["build"] is Number && integer(it["build"],Int.MAX_VALUE.toLong())==release.build }
        require(matches.size==1)
        val notes=matches.single();require(notes["published_at"]==date)
        require(notes["url"]=="https://github.com/sev7enITA/NodeLift/releases/tag/v${release.version}")
        val changes=notes["changes"] as? List<*> ?: error("Expected changes")
        require(changes.size in 1..40)
        val name="NodeLift-${release.version}-android-debug.apk"
        val platform=obj(obj(manifest["platforms"])["android"])
        require(platform["artifact"]==name && platform["status"]=="compiled-debug-signed" && platform["architecture"]=="arm64-v8a")
        val asset=obj(obj(manifest["assets"])[name])
        val url="https://github.com/sev7enITA/NodeLift/releases/download/v${release.version}/$name"
        require(asset["url"]==url)
        val hash=string(asset["sha256"],64);require(hash.matches(Regex("[a-f0-9]{64}")))
        return ReleaseDetails(release,date,string(notes["title"],240),changes.map{string(it,4096)},string(notes["validation"],8192),string(notes["limitations"],8192),name,integer(asset["bytes"],2L*1024*1024*1024),hash,url)
    }
}

private final class UpdateSessionDelegate:NSObject,URLSessionTaskDelegate {

@MainActor final class UpdateMonitor:ObservableObject {
    static let shared=UpdateMonitor()
    @Published private(set) var message:Message="Updates have not been checked yet."
    @Published private(set) var checking=false
    @Published private(set) var available=false
    @Published private(set) var details:ReleaseDetails?
    private let defaults=UserDefaults.standard
    private var started=false
    private var timer:Timer?
    func start(){guard !started else{return};started=true;check()}
    func onResume() {
        if UpdatePolicy.due(now:Date().timeIntervalSince1970,success:defaults.double(forKey:"update-success"),attempt:defaults.double(forKey:"update-attempt")){check()}
        else{schedule()}
    }
    private func schedule() {
        let now=Date().timeIntervalSince1970
        let success=defaults.double(forKey:"update-success");let attempt=defaults.double(forKey:"update-attempt")
        let next=(success>0 && now>=success && now-success<UpdatePolicy.week) ? success+UpdatePolicy.week : attempt+UpdatePolicy.retry
        timer?.invalidate()
        timer=Timer.scheduledTimer(withTimeInterval:max(1,min(UpdatePolicy.week,next-now)),repeats:false){[weak self] _ in Task{@MainActor in self?.onResume()}}
    }
    func check(manual:Bool=false) {
        guard !checking else{return}
        checking=true;available=false;details=nil;message="Checking for updates…";defaults.set(Date().timeIntervalSince1970,forKey:"update-attempt")
        Diagnostics.shared.record(.updateCheck)
        Task {
            let configuration=URLSessionConfiguration.ephemeral
            configuration.timeoutIntervalForRequest=10;configuration.timeoutIntervalForResource=15
            configuration.httpCookieStorage=nil;configuration.urlCredentialStorage=nil;configuration.urlCache=nil
            let session=URLSession(configuration:configuration,delegate:UpdateSessionDelegate(),delegateQueue:nil)
            defer{session.invalidateAndCancel();checking=false;schedule()}
            do {
                let manifest=try await fetch("https://www.fabriziodegni.com/NodeLift/data/mobile-downloads.json",session:session)
                let changelog=try await fetch("https://www.fabriziodegni.com/NodeLift/data/changelog.json",session:session)
                guard let current=CompanionRelease(version:Bundle.main.object(forInfoDictionaryKey:"CFBundleShortVersionString") as? String ?? "",build:Int(Bundle.main.object(forInfoDictionaryKey:"CFBundleVersion") as? String ?? "") ?? 0) else{throw URLError(.cannotParseResponse)}
                let verified=try ReleaseMetadata.parse(manifest:manifest,changelog:changelog,current:current)
                let release=verified.release
                details=verified;available=release>current
                message=available ? Message("Update available: {0} · build {1}",release.version,release.build) : "No newer companion release was found."
                defaults.set(Date().timeIntervalSince1970,forKey:"update-success")
                Diagnostics.shared.record(available ? .updateAvailable:.updateCurrent)
            } catch {available=false;details=nil;message="Update check unavailable. Check your connection or try again later.";Diagnostics.shared.record(.updateFailed,error:error)}
        }
    }
    private func fetch(_ endpoint:String,session:URLSession) async throws -> [String:Any] {
        var request=URLRequest(url:URL(string:endpoint)!)
        request.setValue("application/json",forHTTPHeaderField:"Accept");request.setValue("NodeLift-update-check",forHTTPHeaderField:"User-Agent")
        let (stream,response)=try await session.bytes(for:request)
        guard (response as? HTTPURLResponse)?.statusCode==200,response.mimeType?.lowercased()=="application/json" else{throw URLError(.badServerResponse)}
        var data=Data()
        for try await byte in stream {guard data.count<524288 else{throw URLError(.dataLengthExceedsMaximum)};data.append(byte)}
        guard let object=try JSONSerialization.jsonObject(with:data) as? [String:Any] else{throw URLError(.cannotParseResponse)}
        return object
    }
