# Draft formatting and cached execution: bounded Mac experiment

4 November 2026. Follow-up to the Heretic pilot. No further weight editing. Original pinned Qwen3-4B-Instruct-2507 target and Qwen3-0.6B draft, float16 PyTorch MPS, same package environment. This is a research harness, not a production NodeLift native-backend or physical offload benchmark.

1. Keep all four prior target continuations unchanged. Compare draft proposals using the raw target prefix with proposals using the draft tokenizer's documented `enable_thinking=False` template, followed by exactly the same committed target tokens. Verify the target prefix itself never changes. Generate real k=4 blocks and count only the matching initial run. These are reused diagnostic prefixes, not a new held-out validation set.
2. Freeze six new explicit technical prompts before observing the new results. Run a bounded cached greedy benchmark with 64 output tokens maximum and EOS respected. Compare target-only decoding, raw-template batch speculation, aligned-template batch speculation, aligned-template serial verification, and upstream Transformers assisted generation with fixed k=4. All models remain resident for every arm; model loading is excluded. Run one warmup per arm and three shuffled paired repetitions per prompt. Preserve complete outputs, failures, phase times, candidate counts and first-token readiness.
3. Check custom target-only decoding against upstream greedy generation before benchmarking. Target output equality is a separate gate: faster runs with different output cannot qualify as equivalent acceleration. Strict serial verification must preserve target serial call geometry. Batch verification remains experimental even if this sample matches. Report upstream assisted generation as one comparator, never an exhaustive best-local search.
4. Synchronize MPS for phase timing and explicitly report the instrumentation overhead as part of measured elapsed time. No network, energy, sustained thermals or phone claims. Abort on model errors, nonfinite state, low available memory, or a 30-minute stage limit. No model download or production configuration mutation is planned.

Worker-only formatting is a candidate-generation heuristic. The target retains its original prompt and verifier authority. Equal vocabularies do not imply equal chat templates. Greedy generation is an experimental target contract, not a reproduction of Qwen's recommended sampling-quality setup.
