# Five-case investigation before an architecture decision

Frozen on 5 November 2026 before new inference. Research only. The five cases map to the five limitations identified in the preceding assessment; model sharding remains a separate objective, not a sixth experiment silently substituted for them.

1. **Placement and real overlap:** distinguish sequential local drafting, an independently progressing host, and independent remote compute. First measure an optimistic verifier-only envelope and model candidate arrival with explicitly hypothetical delays. A trace-driven simulation is not a phone benchmark. Obtain fresh node readiness and run bounded application-level transport probes only if a device is online. No prediction of physical speed without a real paired run.
2. **Full cost and admission:** trace initial target/draft prefill, candidate generation, verification, cache rewind, dispatch/bookkeeping and request completion. Compare accounting-only instrumentation against the original generator before changing policy. Evaluate cost-aware decisions with all startup and resynchronization charges. Retain permanent disable; no stale-cache resume.
3. **Optimistic verifier envelope:** generate reference tokens once and make them available to a replay verifier at zero producer/network cost. Replay identical immutable tokens using widths 1, 2, 4 and 8, scoring every next token, fresh caches and matched prefill. This is a teacher-forced timing diagnostic, not free generation or attainable acceleration. Compare logits/argmax and output cap/EOS separately. A numerical disagreement does not invalidate the timing observation but prevents claiming equivalent inference.
4. **Numerical localization:** on a fixed known failing screening prefix, separate current-width effects from history effects. Compare serial history/current-width, serial history/batched current-width, batched history/serial current-width, and batched history/batched current-width. Trace layer boundaries and selected Q/K/V projections, normalization, attention, MLP and final logits. Compare an instrumented path with the installed uninstrumented forward. Do not infer the first faulty kernel solely from the first divergent layer. FP32 is a diagnostic, not a guarantee; no empirical-margin correctness exemption.
5. **Benchmark quality:** record current resource and thermal-pressure telemetry, prohibit this agent's concurrent browser/model/download/hash work while timed inference runs, retain predeclared workload caps and all failures. Inferences on a busy shared Mac remain diagnostic. Use fresh-process repeats and matched paths; bootstrap workloads rather than tokens when a qualification dataset is eventually collected.

## First bounded cycle

Reuse pinned official Qwen3 14B four-bit target and 0.6B draft, MLX 0.32.4 / MLX-LM 0.32.2. Do not download further weights. Use three new diagnostic prompts plus the previously failing screening prompt for localization. Cap generated sequences at 128 tokens. Run the optimistic envelope with native floating parameters and separately with FP32 floating parameters, retaining packed quantized integer weights. Two timing repetitions per prefix/width, shuffled order, independent warmup. No selection or production promotion on these diagnostic prompts.

Resource admission: target plus optional draft must fit measured available memory with working allowance. Keep at least 12 GiB disk free. Per-process timeout 30 minutes and per-request cooperative deadline 180 seconds. Record OS thermal pressure; it is not temperature or energy. Avoid killing user applications or altering system protections. Device/model unavailable means untested, never zero cost.

## Reviews and knowledge base

Ask accessible requested models for separate criticisms of all five cases and bounded unconventional experiments. Record actual model/effort, submitted material, returned excerpts, availability and adjudication. Browser reviews precede timed inference; no simultaneous reviewer UI work during timings. No API spending without available credits. "All models" is not a claim to exhaustive coverage of an unbounded catalogue. Retain proposed, source-supported, locally tested, simulated, physically tested and blocked states separately. No architecture replacement until the five-case evidence matrix is assembled; incomplete physical tests remain explicit.
