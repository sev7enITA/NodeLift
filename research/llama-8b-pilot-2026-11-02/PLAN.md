# Local 8B pilot plan

Frozen before measured runs on 2 November 2026. Objective: establish a real larger-model NodeLift host-only baseline and test whether the existing local-draft path helps on the Mac. This is not a phone or PC benchmark.

Use the already installed Ollama Llama 3.1 8B Q4_K_M target and Llama 3.2 3B Q4_K_M draft, without copying or distributing either model. A preflight verified matching token fingerprints and native chat-template availability. Use a clean NodeLift checkout at `7d7b14a2d8b6aaeac9406fa2fbdb669bfb7ae42f`, the standard native library with experimental deferred draft disabled, requested GPU layers 999, context 2048 and eight threads. The target, draft, executable and source hashes are recorded by the runner.

Run the existing `scripts/benchmark-engine.py` plan unmodified: six generic prompts, two repetitions, five modes per prompt/repetition (host-only, local draft widths 1, 4, 8 and 16), with 64-token maximum, greedy decoding and EOS respected. Fixed seed 20261031 shuffles the 60 conditions; paired results match prompt and repetition. Warm both models before measurement and retain the model residency caveat for host-only runs. Keep every result, output hash/token sequence, failure and mismatch. No condition or prompt will be excluded after observing results. If the script aborts, report the interrupted plan and retain partial records.

Measure NodeLift request wall time including prefill and detokenization, excluding model loading after warmup; compare equal output token sequences separately from mismatches. An observed speed result is not a general guarantee, and timing cannot be compared directly with an upstream or mobile server using a different path. Treat the period as one exploratory session, not an independent confidence interval; monitor thermal/load limitations. Energy and effective GPU placement are unmeasured. Keep earlier small-target phone measurements separate. Follow-up experiments must compare against an independently optimized local runtime and include independent sessions before any superiority claim.
