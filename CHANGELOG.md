# Changelog

## Documentation and repository update — 1 November 2026

- Wiki and how-to hub: first host run, Android, iOS, model sources/providers, benchmarking, troubleshooting, architecture and workflow scope.
- English, Simplified Chinese and Italian README entry points; current 0.2.3 download links; captioned gallery using existing project artwork and real showcase captures.
- Read-only setup inventory, documentation link checks, manual published-release integrity checks and manual native compilation workflow.
- Structured bug/benchmark forms, PR guidance and security reporting instructions.
- Pinned REA source study with adopted patterns and unimplemented engine candidates distinguished.

This documentation/tooling update does not produce a new mobile binary or establish physical-device performance.

## [0.2.3](https://github.com/sev7enITA/NodeLift/releases/tag/v0.2.3) — 1 November 2026

Companion build 5 adds Italian alongside default English and Simplified Chinese. Shared catalog: 557 entries. Android and unsigned iOS packages compiled; physical-device UI qualification remains open. Native binaries are unchanged from 0.2.2.

The tagged source includes the host 0.3.0 integration preview: public Hugging Face GGUF search/download, direct file/path import, explicit OpenRouter and loopback local-server routes. See the integration validation record for observed tests and unresolved paths.

## [0.2.2](https://github.com/sev7enITA/NodeLift/releases/tag/v0.2.2) — 1 November 2026

Companion build 4 added default English, Simplified Chinese and persisted language selection. The source also included measured adaptive control, context lookup and greedy argmax caching, with bounded observed evidence.

## [0.2.1](https://github.com/sev7enITA/NodeLift/releases/tag/v0.2.1) — 31 October 2026

Native greedy verification, authenticated remote work, text gateway, companion builds and LM Studio adapter. Initial real-weight control comparisons found local drafting slower on the tested small pair. Physical-phone acceleration and memory pooling were not established.
