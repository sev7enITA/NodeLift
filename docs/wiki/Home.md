# NodeLift documentation

**Give the hardware you already own another useful role in local AI.**

NodeLift is an experimental shared local execution service and companion system, created by **Fabrizio Degni**. Its objective is to make device RAM and compute available through everyday AI interfaces. The desktop control room manages the service, and adapters connect clients. The current native path uses draft proposals verified by the host; memory-capacity sharding remains to be implemented and physical-phone speedup remains unproven. See the [product direction and roadmap](https://github.com/sev7enITA/NodeLift/blob/main/docs/ROADMAP.md).

Current download: [companion 0.2.5 / build 7](https://github.com/sev7enITA/NodeLift/releases/tag/v0.2.5). Host sources include the 0.3.0 integrations preview. English is the default app language; Simplified Chinese and Italian are available offline.
