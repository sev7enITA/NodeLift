# NodeLift documentation

**Give the hardware you already own another useful role in local AI.**

NodeLift is an experimental host, inference engine and mobile companion system, created by **Fabrizio Degni**. A small draft model can propose tokens while the host target verifies them. The current engine does not pool phone RAM; physical-phone speedup remains unproven.

Current download: [companion 0.2.3 / build 5](https://github.com/sev7enITA/NodeLift/releases/tag/v0.2.3). Host sources include the 0.3.0 integrations preview. English is the default app language; Simplified Chinese and Italian are available offline.
